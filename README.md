# Smart Travel Planner

#About the Project
Smart Travel Planner is a web-based application developed as an MCA project. It helps users explore travel destinations and plan trips based on their preferences, budget, number of days, and number of people.

#Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

# Features
- Explore travel destinations
- View destination details and images
- Plan trips based on budget and duration
- Select travel interests
- Generate a day-wise itinerary
- User registration and login

# Project Structure
- `app.py` – Flask application
- `templates/` – HTML templates
- `static/` – CSS and images
- `.gitignore` – Files excluded from Git

# How to Run
1. Install Python.
2. Install the required Python packages.
3. Configure the MySQL database.
4. Run the Flask application using `python app.py`.
5. Open `http://127.0.0.1:5000` in your browser.

# Project Purpose
This project was developed to practice web development, database connectivity, and travel itinerary planning.
